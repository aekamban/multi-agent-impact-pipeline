## CURRICULUM STANDARDS — SCOPE & EXTENSIBILITY

### POC Scope (US English only)
- NGSS (Next Generation Science Standards)
- Common Core ELA/Literacy in Science

### Designed-in extensibility (add after POC, not a rebuild)
- UK: GCSE Science, A-Level Biology/Chemistry/Environmental Science,
  AQA/OCR/Edexcel specifications
- IB: MYP Sciences, MYP Individuals & Societies,
  DP Environmental Systems & Societies (ESS), DP Geography
- Rationale for early addition: IB is used at English-speaking
  international schools in 90+ countries — covers TCI's international
  educator base without requiring translation

### Schema fields supporting extensibility (already in schema_v2)
In teachers table:
  curriculum_standard TEXT DEFAULT 'NGSS'
  -- values: 'NGSS', 'Common_Core', 'UK_GCSE', 'UK_A_Level',
  --         'IB_MYP', 'IB_DP_ESS', 'IB_DP_Geo', 'Other'
  country TEXT  -- already present

In sessions table:
  curriculum_standard TEXT DEFAULT 'NGSS'
  -- session-level override (teacher may run different standards
  -- for different classes in same year)

### CRITICAL BUILD RULE FOR ALL AGENTS
NEVER hardcode 'NGSS' as the only standard in any prompt or logic.
Always branch on session.curriculum_standard.
For POC: only NGSS branch has full content.
Other branches return:
  "This standard is coming soon — your feedback helps us prioritize it!"

## AGENT 1 — CURRICULUM ALIGNMENT STANDARDS REFERENCE

### How Agent 1 uses standards
Teacher pre-survey captures:
  - Subject area (e.g. "Chemistry", "Biology", "Social Studies")
  - Grade band (elementary/middle/high)
  - Curriculum standard (NGSS / UK GCSE / IB MYP etc.)
  - Current unit/topic being taught

Agent 1 then:
1. Identifies which TCI learning lab(s) connect to their subject + standard
2. Suggests specific connection points ("This lab's carbon footprint 
   calculations align with NGSS HS-ESS3-4...")
3. Drafts a 2-3 sentence "curriculum justification" the teacher can 
   use with their department head
4. Suggests project types that fit both the lab AND the curriculum context

### NGSS alignment table (US POC — core reference for Agent 1)
To be loaded from: documents/ngss_alignment.md (generated by ChatGPT)
Format: lab_name → [NGSS codes, subject areas, curriculum pitch]

## LANGUAGE — SCOPE & EXTENSIBILITY

### POC Scope
English only.

### TCI's actual language coverage
Up to 9 languages across the 11 learning labs.
Priority additions post-POC (guided by TCI usage data):
  Spanish (largest non-English TCI educator base)
  French (significant African educator base)
  Portuguese (Brazil — Agriculture lab most popular globally)

### Build rule: NO HARDCODED STRINGS IN UI
All user-facing text must come from strings.py language dictionary.
Structure:

  STRINGS = {
      "en": {
          "welcome_teacher": "Welcome! Let's set up your learning lab.",
          "welcome_student": "Welcome! What are you working on today?",
          "phase_planning": "Planning",
          "phase_implementing": "Implementing", 
          "phase_analyzing": "Analyzing & Reporting",
          # etc — every UI string goes here
      }
      # "es": {...}  ← add later, zero code changes needed
      # "fr": {...}
      # "pt": {...}
  }

Language selector in Streamlit UI:
  - Default: "en"
  - Dropdown visible but only "English" enabled for POC
  - Other languages show "Coming soon" — signals roadmap to TCI

### Pitch language for demo
"The app is architected for multilingual support from day one.
Adding Spanish — which would serve TCI's largest non-English
educator base — is a content project, not a rebuild. 
Estimated: 3-4 weeks of translation + testing."
